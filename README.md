# -GPTpetv4
璃的人物设计保持不变：白发紫瞳、白色龙角、尖耳、淡紫翅膀与尾巴、白紫裙装。v4 改用清晰的深紫描线、大色块平涂和少量赛璐璐阴影，并把虎头帽动作放到鼠标悬停时触发。  ## Windows 快速安装  1. 先完整解压 ZIP。 2. 双击 `安装紫璃.cmd`，把成品复制到客户端的本地宠物目录。 3. 回到客户端宠物设置，点击 **Refresh / 刷新**，选择 **紫璃 v4** 并显示宠物。 4. 把鼠标移出紫璃，再移回她身上，查看虎头帽动作。  再次安装同一 v4 文件夹时使用 `更新紫璃.cmd`，会先备份该文件夹。安装不会自动选中宠物；包内另有手动导入方法。
